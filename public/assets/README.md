# Asset Guide

Place assets in their matching directories:

- `models/` — GLB/GLTF 3D models
- `textures/` — planet, terrain, material and effect textures
- `environments/` — HDR/EXR environment maps
- `videos/` — cinematic MP4/WebM footage
- `audio/` — ambient and interaction sound

Use appropriately licensed assets and record attribution/license details when required.
